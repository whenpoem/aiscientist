# Cockpit 键位参考

> English version: [cockpit-keys.md](cockpit-keys.md)
> Textual cockpit 的完整键位表，按作用域分类。cockpit 里每个注册过的
> 快捷键都应该在本页有对应行。如果加了新键位但本页没更新，就是文档漂
> 移。

每个快捷键属于以下四种作用域之一。作用域决定了你必须把焦点放在哪里，
按键才会生效。

## 全局（优先级键位）

无论焦点在哪个面板、哪个弹窗、哪个表格上，这些键都会生效。它们的优
先级高于当前聚焦控件自带的键位。

| 键 | 动作 |
|---|---|
| `L` | 切换语言（中英文）|
| `T` | 轮换主题 |
| `F` | 切换单面板聚焦模式 |
| `H` | 中止当前 agent 回合 |
| `R` | 强制刷新当前状态 |
| `N` | 跳到下一个标签页分组（跨主干 → 实验 → 证明）|
| `P` | 显示 / 隐藏阶段栏（v5.0）|
| `M` | 开启 / 关闭活动面板动画（v5.0）|
| `a` / `A` | 显示 / 隐藏审计日志视图（v5.0）|
| `b` | 收藏 / 取消收藏当前选中节点（v5.1）|
| `B` | 打开收藏夹导航弹窗（v5.1）|
| `u` | 撤销最近一次干预（仅在尚未投递时有效）|
| `<` / `>` | 收窄 / 放宽宽屏布局中的树形列 |
| `q` | 退出（如果有叠加屏幕则先关掉它）|
| `Esc` | 取消当前操作（关弹窗、退出过滤等）|
| `Ctrl+L` | 清空审计日志（原事件面板）|
| `Ctrl+P` | 打开命令面板 |

App 里有一个优先键位转发机制：当焦点在输入框上时，按大写优先键会直
接输入字面字符，不会触发对应的功能。比如在弹窗的文本框里打 `L` 就是
输入字母 L，不会切语言。这个机制覆盖 `L T F H R N u < >`，以及
v5.0 新增的 `P M a A`，以及 v5.1 新增的 `b B`。

## 选中动作

这类键作用于**树形列表里当前选中的节点**，不管此时哪个面板有焦点。
它们是 App 级的普通（非优先）键位。

| 键 | 动作 |
|---|---|
| `y` | 批准选中节点 |
| `n` | 拒绝选中节点 |
| `r` | 重定向选中节点 |
| `c` | 约束选中节点 |
| `m` | 标记选中节点为已驳倒 |
| `p` | 在选中节点上钉一个指标 |

## 移动

移动键在每个可聚焦的面板里都能用。具体含义随面板变化（移动树游标、
滚动事件日志、翻标签页行），但键位注册在 App 级。

| 键 | 动作 |
|---|---|
| `j` / `k` | 下移 / 上移 |
| `h` / `l` | 折叠 / 展开，或左移 / 右移 |
| `g` / `G` | 跳到顶部 / 底部 |
| `1` – `4` | 聚焦 树 / 详情 / 活动 / 标签页 面板（`3` 在 v5 之前对应事件面板，settings 加载时自动修正）|
| `Tab` / `Shift+Tab` | 切到下一个 / 上一个面板 |
| `Enter` | 进入选中项的详细视图 |
| `f` | 在当前分组内切到下一个标签页 |

## 面板级

只在指定面板聚焦时生效。从其他面板按这些键**不会有反应**——因为对应
的操作只在那个面板里才有意义，cockpit 有意不把它们提升为全局键位。

| 面板 | 键 | 动作 |
|---|---|---|
| 审计日志（原事件面板）| `w` | 切换事件内容的自动换行——先用 `a` / `A` 打开并聚焦审计日志 |
| 审计日志（原事件面板）| `t` | 切换相对时间 / 绝对时间显示 |
| 树 | `i` | 切换树标签紧凑模式（显示或隐藏 BT 分数和 Elo）|

## 弹窗 / 过滤输入框

在弹窗或过滤 / 命令行输入框里，只有 `Escape`、`Enter`、`Tab` /
`Shift+Tab` 被当作命令。其他键一律按字面字符输入。

## 底栏行为

Textual 的底栏（`Footer`）从当前聚焦控件向上逐层读取键位表。焦点在
审计日志上时，底栏应该显示 `w Wrap`；焦点在树面板上时，应该显示
`i Tree info`。全局键（`L T F` 等）无论焦点在哪都会显示。

## 添加新键位

先确定作用域：

- **全局**——只有"无论用户在看什么都应该生效"的操作才放这里。优先级
  键位的门槛很高，因为每加一个优先字母，转发机制都要同步覆盖。
- **选中动作**——作用于树里选中的节点。加进 App 的普通 `BINDINGS` 列
  表，同时在上面的表格里补一行。
- **移动**——同选中动作。
- **面板级**——在面板类上声明 `BINDINGS = [...]` 加对应的
  `action_<name>` 方法。面板的键位写在面板模块里，不要写在
  `app.py` 里。

如果新加了键位但在本页找不到对应行，文档就已经落后了。合并前补上。
